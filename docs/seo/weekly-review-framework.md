# Weekly SEO Review Framework

This review must be run every Monday to answer 5 strategic questions using GSC and GA4.

## 1. Which tools are breaking out?
- **GSC Filter**: Date range = Last 7 days vs Previous 7 days. Metric = Impressions & Clicks.
- **Action**: For breakout tools, immediately audit internal linking pointing *to* this tool to accelerate its growth. Double-check ad/affiliate placement.

## 2. Which pages have high impressions but low CTR?
- **GSC Filter**: Date range = Last 28 days. Sort by Impressions (High to Low). Look for CTR < 2%.
- **Action**: These are metadata optimization candidates. Run the title/description through the automated pipeline variations, test a more compelling hook.

## 3. Which keywords have high impressions but poor ranking positions (latent potential)?
- **GSC Filter**: Queries report. Impressions > 500, Position > 15.
- **Action**: The content isn't authoritative enough. Add an FAQ section, inject more specific schema, or write a supporting Hub article that links to this page.

## 4. Which pages have impressions but zero clicks (intent mismatch)?
- **GSC Filter**: Pages report. Clicks = 0, Impressions > 1000.
- **Action**: Google thinks this might be relevant, but the user doesn't. Check the query. Is the intent navigational (they want a specific competitor brand) or informational (they want a definition, not a tool)? Adjust page structure or canonicalize.

## 5. What new tools should be built based on keyword data?
- **GSC Filter**: Queries report. Filter by queries containing "tool", "generator", "converter" where we rank > 50.
- **Action**: Feed these into the programmatic SEO generation pipeline.
