# Inter-Cluster Semantic Linking Strategy

Cross-linking between clusters builds a semantic entity graph, showing Google we are an ecosystem, not just isolated tools.

## Implementation Rules
1. **Context is King**: Only cross-link when there is a natural workflow overlap.
2. **Limit**: Max 1-2 cross-cluster links per page to avoid diluting topical focus.
3. **Anchor Text**: Use exact or partial match intent-driven anchor text, not generic "click here".

## Example Overlaps

| Source Cluster | Target Cluster | Workflow Overlap / Rationale | Anchor Text Idea |
| :--- | :--- | :--- | :--- |
| **Color Tools** (Color Palette Gen) | **Resume Tools** (Resume Templates) | Users picking colors for personal branding might be building a resume. | "apply this palette to a professional resume template" |
| **PDF Tools** (Merge PDF) | **Business Cards** (Export PDF) | Users exporting business card PDFs might need to merge them with cover letters. | "merge your exported business cards" |
| **Calculators** (Salary Calc) | **Resume Tools** (ATS Checker) | Users calculating salary are job hunting. | "optimize your resume for ATS systems" |
